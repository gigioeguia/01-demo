# AGENTS.md

## Overview

Single static `index.html` page. No build system, package manager, tests, or lint/typecheck tooling.

## Workflow

- To verify changes, open `index.html` directly in a browser. There is no dev server or build step.
- Styling currently lives in an inline `<style>` block in `index.html`. `README.md` lists Tailwind CSS and JavaScript, but neither is set up yet — don't assume tooling exists.

## Conventions

- User-facing content (visible text, `README.md`) is in Spanish.
- `README.md` is aspirational about the tech stack; trust the actual code over the docs.
